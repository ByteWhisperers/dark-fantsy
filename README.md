# Darck Fantasy — Mapa do projeto

Mundo de fantasia sombria construído a partir de um conto e de um pré-worldbuild do autor (Hermes).
Projeto longo. Ritmo: **anotar → pensar → pesquisar → escrever**. Nada vira cânone sem decisão explícita.

## Duas camadas
Pastas 03–08 = **mundo** (existe sem a história). `09-narrativa/` = **narrativa** (o que acontece, sempre com causas no mundo). Detalhes em `CONVENCOES.md`.

## Pastas

| Pasta | Para quê |
|---|---|
| `00-fontes/` | Material original do autor (o conto, o pré-worldbuild). **Nunca é editado**, só lido e citado. |
| `01-notas/` | Caixa de entrada: ideias soltas, rascunhos rápidos. `sessoes/` guarda o registro de cada sessão de trabalho. |
| `02-pesquisa/` | Referências reais e inspirações (história, mitologia, obras, D&D). Sempre com fonte. |
| `03-lore/` | Cosmologia, deuses e religiões, magia, história e cronologia. |
| `04-povos/` | Raças/espécies e culturas. |
| `05-geografia/` | Regiões, lugares, clima, mapas. |
| `06-faccoes/` | Reinos, ordens, cultos, organizações. |
| `07-personagens/` | Figuras do conto e do mundo. |
| `08-sistema/` | D&D 5e como norte técnico: guia SRD e adaptações da casa. |
| `09-narrativa/` | **Camada narrativa**: eventos e arcos de Argon, Malakor e demais. Cada evento liga a causas no mundo. |
| `_modelos/` | Modelos de documento para copiar. |

## Arquivos-chave
- [`CONVENCOES.md`](CONVENCOES.md) — como escrevemos, nomeamos e marcamos o status das coisas.
- [`CANONE.md`](CANONE.md) — registro das decisões travadas. Se não está aqui, não é cânone.
- [`PERGUNTAS-ABERTAS.md`](PERGUNTAS-ABERTAS.md) — dúvidas e lacunas a resolver.
- [`GLOSSARIO.md`](GLOSSARIO.md) — termos e nomes próprios do mundo.
- [`08-sistema/guia-srd-5e.md`](08-sistema/guia-srd-5e.md) — referência do D&D 5e para worldbuilding.

## Fluxo de trabalho
1. Ideia nova → `01-notas/` (status `ideia`).
2. Precisa de base? → pesquisa em `02-pesquisa/`, dúvida em `PERGUNTAS-ABERTAS.md`.
3. Amadureceu → vira documento na pasta temática (status `rascunho`).
4. Autor aprova → status `canone` + linha no `CANONE.md`.
5. Fim de cada sessão → registro em `01-notas/sessoes/AAAA-MM-DD.md`.
